Privacy Policy

What this site collects

ReagentRoute doesn't require an account, and doesn't use cookies or tracking scripts of its own. Here's exactly what happens with the inputs on the page:

  • Profession, skill range, realm, and faction you select are sent to our server so it can fetch live Auction House prices and compute a leveling plan. They're used only to build the response for that single request and aren't logged or stored anywhere.
  • "Materials you already own" is sent to our server the same way, so the plan can account for what you already have. It is processed in memory to compute that one response and is not written to a database, file, or log -- we don't have a database.

Standard web server request logs (e.g. Render's, our hosting provider) may briefly record technical details like your IP address and request timestamp, the same as effectively every website on the internet. We don't access these for any purpose beyond debugging.
